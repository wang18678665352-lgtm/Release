# 电子医疗管理系统 (Electronic Medical Management System)

## 项目简介
本项目是一个基于 C 语言开发的轻量级电子医疗管理系统。系统采用二进制文件 (.dat) 进行数据存储，无需配置复杂的数据库环境。目前支持管理员、医生、患者三种角色，涵盖了从挂号到诊疗的全流程管理。

## 系统架构
*   **核心语言**: C 语言
*   **编译环境**: 内置 MinGW-w64 (GCC 15.2.0)
*   **数据存储**: 二进制文件系统 (data/*.dat)
*   **编码方案**: 源码采用 UTF-8 编码。编译时通过 `-fexec-charset=GBK` 参数，确保在 Windows CMD (chcp 936) 环境下完美显示中文，彻底解决乱码问题。
*   **模块化设计**: 系统划分为 common, login, patient, doctor, admin, public, data_storage 七大核心模块，结构清晰，易于维护。

## 接口设计
*   **菜单接口**: 统一采用 `int module_name_menu(const User *current_user)` 签名。函数返回状态码（如 SUCCESS, ERROR_NOT_FOUND, ERROR_INVALID_INPUT 等），便于全局状态管理。
*   **存储接口**: 使用 `int load_xxx(Xxx **arr, int *count)` 和 `int save_xxx(const Xxx *arr, int count)` 模式。通过双指针实现动态内存分配，灵活处理不同规模的数据。

## 使用说明
1.  解压后直接双击 `启动.bat` 即可运行，无需手动配置任何环境变量。
2.  **默认账号密码**:
    *   管理员: `admin` / `admin123`
    *   医生: `doctor1` 到 `doctor7` / `doctor123`
    *   患者: 可以在主界面选择 `2. 注册用户` 自行创建。
